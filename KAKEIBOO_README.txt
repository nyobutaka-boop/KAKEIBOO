KAKEIBOO Local Edition（GitHub Pages公開版）

- AppDeployを使用しない、ブラウザ内保存型の家計簿アプリです。
- GitHub PagesでHTTPS公開して、Androidのホーム画面に追加して使えます。
- 初回起動時は空の家計簿として開始します。
- 家計簿データと画像はブラウザのIndexedDBに保存され、公開サイトには送信されません。
- 以前のデータを移す場合は、アプリの「設定」→「データのバックアップ・復元」から、手元にあるKAKEIBOOのバックアップJSONを選択して復元してください。
- 復元前に現在の端末データをバックアップしてください。復元は現在のデータを置き換えます。
- ブラウザのデータ消去・端末故障・端末変更で失われる可能性があるため、定期的にバックアップを書き出してください。
- レシートOCRはまだ実装していません。画像添付と手入力に対応します。外部OCRサービスやAI APIを追加する場合は、通信・費用・画像の外部送信について事前確認が必要です。

【プライバシー】
この公開用フォルダーには、家計簿の記録・レシート画像・個人用バックアップJSONを含めません。
